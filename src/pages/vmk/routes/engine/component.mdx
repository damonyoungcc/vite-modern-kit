# Router Engine

The Router Engine is responsible for turning the `src/pages/` directory into a dynamic React Router v6 tree. It relies on a Vite virtual module (e.g. virtual:vmk-routes) that exports the current route configuration.
This virtual module is automatically regenerated whenever the filesystem changes, so developers don’t have to maintain a manual route config.


## How It Works
 1. The Vite plugin scans `src/pages/` for `page.tsx`, `page.noWrap.tsx`, and `_layout.tsx` files.
 2. It builds a route tree that mirrors the filesystem structure.
 3. The plugin provides the tree via the virtual module `virtual:vmk-routes`.
 4. React Router v6 consumes it with `useRoutes()`.

<strong>Example usage:</strong>

```tsx
// router.tsx
import { useRoutes } from 'react-router-dom';
import routes from 'virtual:vmk-routes';

export function AppRouter() {
  return useRoutes(routes);
}
```

## Hot Module Replacement (HMR)

Triggered when only the content of a file changes (no impact on the route structure).
- Examples: editing a component inside `page.tsx` or `_layout.tsx`.
- Behavior:
  - The file updates in place.
  - The route tree remains unchanged.
  - React re-renders the affected component via HMR.
  - Benefit: developers see changes instantly without losing application state.

## Full Reload

Triggered when a filesystem change may affect the route tree.
- Examples:
  - Adding or removing a `page.tsx` or `page.noWrap.tsx`.
  - Renaming a dynamic segment folder (e.g. `[id] → [userId]`).
  - Adding or removing a `[...all]` fallback directory.
- Behavior:
  - The plugin regenerates the full route tree.
  - Vite forces a full reload to ensure React Router gets the correct structure.
  - Benefit: keeps the router configuration consistent with the filesystem, avoiding stale or broken routes.

## Design Benefits
- Zero Manual Config: The filesystem is the single source of truth for routes.
- Fast Feedback Loop: File changes are reflected instantly via HMR.
- Consistency & Safety: Automatic fallback to full reload on breaking changes keeps the app stable.
- React Router Native Fit: Routes are assembled as a nested tree, perfectly aligned with React Router v6’s useRoutes().
