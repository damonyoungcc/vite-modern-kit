# File-Based Routing System Architecture

This project implements a scalable <strong>file-based</strong> routing system using <strong>Vite</strong> and <strong>React Router v6</strong>.  
It leverages Vite’s <strong>virtual module</strong> feature to scan the <code>src/pages</code> directory apply convention-based rules to generate paths build a tree of routes that fully aligns with React Router best practices:

- route matching
- intuitive layout nesting
- fallback handling

By injecting this tree via a virtual module, the system delivers a zero-configuration, convention-over-configuration experience that reduces boilerplate, ensures team-wide consistency, and scales seamlessly for enterprise React applications.

## 📁 Example Directory Structure

```markdown
src/
└── pages/
    ├── _layout.tsx               # Global layout
    ├── a/
    │   ├── _layout.tsx           # /a layout
    │   ├── index/page.tsx        # /a
    │   └── [id]/page.tsx         # /a/:id
    ├── b/
    │   └── page.noWrap.tsx       # /b (no Global layout)
    ├── c/
    │   ├── index/page.tsx        # /c
    │   └── [...all]/page.tsx     # /c/* scoped fallback
    └── 404/page.tsx              # Global fallback (*)
```

## Generated Route Config

```jsx
[
  {
    path: "/",
    element: <GlobalLayout />,
    children: [
      {
        path: "a",
        element: <ALayout />,
        children: [
          { path: "", element: <APage /> },
          { path: ":id", element: <ADetailPage /> }
        ]
      },
      {
        path: "c",
        element: <GlobalLayout />,
        children: [{ path: "*", element: <CFallback /> }]
      },
      { path: "*", element: <NotFoundPage /> }
    ],
    { path: "/b", element: <BPage />, noWrap: true },
  }
];
```

## 🗂️ Naming Rules

- **`index/page.tsx`**  
  → Renders the exact route of its parent directory.  
  Example: `src/pages/a/index/page.tsx` → `/a`

- **`_layout.tsx`**  
  → Provides layout for its directory and all descendants.  
  Example: `src/pages/a/_layout.tsx` wraps `/a` and all `/a/*` children.

- **`page.noWrap.tsx`**  
  → Renders a page without inheriting any parent layouts.  
  Example: `src/pages/b/page.noWrap.tsx` → `/b` without wrapping `_layout.tsx`.

- **`[param]/page.tsx`**  
  → Defines a dynamic parameter route.  
  Example: `src/pages/a/[id]/page.tsx` → `/a/:id`

- **`[...all]/page.tsx`**  
  → Scoped fallback: catches unmatched paths inside a directory.  
  Example: `src/pages/c/[...all]/page.tsx` → `/c/*`

- **`404/page.tsx`**  
  → Global fallback: final catch-all for the app.  
  Example: `src/pages/404/page.tsx` → `*`
